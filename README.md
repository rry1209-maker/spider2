# 사회정서역량 진단 설문

학생이 20문항(5개 영역 × 4문항)에 응답하면 5각형 레이더 차트로 자신의 사회정서역량 프로파일을 확인하고,
교사는 같은 화면에서 학급 전체 결과를 조회·내려받을 수 있는 한 개짜리 HTML 파일입니다.
설치·서버·데이터베이스가 필요 없습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 설문·결과·교사 화면이 모두 들어 있는 단일 파일 |

## 사용 방법

**학생용 설문** — 이름을 입력하고 20문항에 1~5점으로 응답한 뒤 `결과 보기`를 누르면
영역별 점수(10점 만점)와 레이더 차트가 나옵니다. `내 결과 파일로 저장`을 누르면 JSON 파일이 저장되고,
`인쇄 / PDF 저장`으로 결과지를 출력할 수 있습니다.

**교사용 결과 보기** — 제출 인원, 학급 평균, 강점·보완 영역이 먼저 보이고
학생 카드를 누르면 문항별 응답과 학급 평균(점선) 대비 프로파일을 볼 수 있습니다.
`엑셀(CSV) 내려받기`로 전체 응답을 표로 받을 수 있습니다.

## 데이터가 저장되는 곳

응답은 **그 기기의 브라우저 저장소(localStorage)** 에만 저장됩니다. 서버로 전송되지 않습니다.

- 교실 공용 PC/태블릿 한 대에서 학생들이 번갈아 응답 → 교사 모드에서 전원 결과가 바로 보입니다.
- 학생이 각자 기기에서 응답 → 결과가 각 기기에 남습니다. 학생이 `내 결과 파일로 저장`으로 받은 JSON을 제출하고,
  교사가 `학생 결과 파일 불러오기`로 여러 개를 한 번에 선택하면 하나로 합쳐집니다.
- 브라우저 방문 기록을 지우면 데이터도 사라지므로, 수업 후 `백업 파일 저장`을 권합니다.

## GitHub에 올리고 웹 주소 만들기

1. GitHub에서 `New repository` → 이름 입력(예: `sel-survey`) → **Public** 선택 → `Create repository`
2. `uploading an existing file` 링크를 눌러 `index.html`(과 `README.md`)을 끌어다 놓고 `Commit changes`
3. `Settings` → 왼쪽 `Pages` → Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 두고 `Save`
4. 1~2분 뒤 `https://아이디.github.io/sel-survey/` 주소로 접속됩니다. 이 주소를 학생에게 QR이나 링크로 공유하세요.

> 저장소를 Private으로 두면 GitHub Pages는 유료 플랜에서만 동작합니다. 설문 내용에 개인정보가 없다면 Public으로 두세요.

## 문항·디자인 고치기

`index.html` 아래쪽 `<script>` 안 **1. 설정** 구역만 수정하면 됩니다.

- `questions` 배열에서 문항 문구를 바꾸거나 추가·삭제 (`domain` 값은 5개 영역 키 중 하나)
- `domains` 배열에서 영역 이름·아이콘·색상 변경
- 영역별 문항 수가 달라도 점수는 자동으로 10점 만점으로 환산됩니다

색상은 파일 맨 위 `:root`의 CSS 변수(`--bg`, `--accent` 등)를 바꾸면 전체에 적용됩니다.

## 원본(캔바 AI 코드)에서 달라진 점

- 캔바 전용 SDK(`element_sdk`, `data_sdk`, 부트스트랩 스크립트) 제거 → 어디서나 단독 실행
- 점수 환산식 수정: 5점 평균 × 2.5(최대 12.5점)라 차트 밖으로 나가던 것을 × 2(최대 10점)로 정정
- 교사 상세 화면에서 목록 컨테이너의 부모를 숨겨 화면 전체가 사라지던 문제 수정
- 문항 카드의 `class` 속성 안에 CSS가 잘못 들어가 구분선이 그려지지 않던 문제 수정
- 응답 진행률 표시, 미응답 문항 자동 이동, CSV·JSON 내보내기/불러오기, 학급 평균 비교, 삭제, 인쇄 기능 추가
- 키보드 포커스 표시, 모바일 대응, 화면 낭독기용 레이블 보강
